# CRISPRcleanR Functions

Returns the CRISPRcleanR functions used by
[`correct_crispr_bias`](https://emanuelsoda.github.io/ScreenR/reference/correct_crispr_bias.md),
or stops with installation instructions when CRISPRcleanR is not
installed.

## Usage

``` r
crisprcleanr_functions(package = "CRISPRcleanR")
```

## Arguments

- package:

  The name of the package (only changed in the tests).

## Value

A list of functions.
