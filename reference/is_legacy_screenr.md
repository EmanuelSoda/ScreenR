# Is a ScreenR Object of an Older Version

Internal function that tells whether an object was created with a
version of ScreenR older than 1.15.8, in which the screenr_object class
was not a SummarizedExperiment.

## Usage

``` r
is_legacy_screenr(object)
```

## Arguments

- object:

  A ScreenR object.

## Value

TRUE or FALSE.
