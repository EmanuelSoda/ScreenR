# Control Barcodes

Internal function that checks the control barcodes of the "control"
normalization against the barcodes of the object.

## Usage

``` r
control_reference(object, control_barcodes)
```

## Arguments

- object:

  A ScreenR object.

- control_barcodes:

  The identifiers of the control barcodes.

## Value

The identifiers of the control barcodes that are in the object.
