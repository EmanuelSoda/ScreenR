# Check the Palettes

Internal function that checks the palettes of the sample variables and
returns them named by the values of each variable.

## Usage

``` r
check_palettes(palettes, col_data)
```

## Arguments

- palettes:

  A named list of color vectors.

- col_data:

  The colData of the object.

## Value

The palettes, as a named list of named character vectors.
