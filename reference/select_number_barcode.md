# Select number of Barcode

Compute a unique gene symbol for gene

## Usage

``` r
select_number_barcode(gene, gene_symbols, number_barcode)
```

## Arguments

- gene:

  The gene name

- ...:

  Arguments passed on to
  [`unique_gene_symbols`](https://emanuelsoda.github.io/ScreenR/reference/unique_gene_symbols.md)

  `gene_symbols`

  :   The gene symbols list

## Value

The barcode of the gene passed as input
