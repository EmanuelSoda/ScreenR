# Is CRISPRcleanR Available

Tells whether the CRISPRcleanR package, used by
[`correct_crispr_bias`](https://emanuelsoda.github.io/ScreenR/reference/correct_crispr_bias.md),
is installed. It is not on CRAN or Bioconductor: install it with
`BiocManager::install("francescojm/CRISPRcleanR")`.

## Usage

``` r
crisprcleanr_available()
```

## Value

TRUE or FALSE.

## See also

[`correct_crispr_bias`](https://emanuelsoda.github.io/ScreenR/reference/correct_crispr_bias.md)

## Examples

``` r
crisprcleanr_available()
```
